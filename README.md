# 🌱 KrishiMitra – Smart Farming Assistant

**Empowering Farmers with Smart Technology for a Better Harvest.**

KrishiMitra is a frontend-based smart farming assistance platform designed to help farmers access useful agricultural information and make better farming decisions through a simple, user-friendly interface.

## 🚀 Features

- 🌾 **Crop & Seed Recommendation** – Explore crop options based on soil type, pH, season and water availability.
- 📸 **Crop Disease Scanner UI** – Capture or upload leaf images for future AI-based disease detection integration.
- 🐛 **Pest Management** – Learn about common crop pests, symptoms and management practices.
- 🧪 **Soil & Fertilizer Guidance** – Understand soil pH, moisture and essential nutrients.
- 🌦️ **Weather Forecast** – Get weather information using the Open-Meteo API.
- 💰 **Market Price Resources** – Access official agricultural market information.
- 📚 **Farming Learning Centre** – Explore farming tutorials and educational videos.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Responsive Web Design

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the KrishiMitra platform in your browser.

## ⚠️ Current Limitations

This is a frontend prototype. Disease classification is not yet implemented, soil readings are entered manually, and live mandi prices are not displayed inside the website.

## 🎯 Project Goal

To make agricultural information accessible, support informed farming decisions, reduce avoidable crop losses and encourage sustainable agriculture.
